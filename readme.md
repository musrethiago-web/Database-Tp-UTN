# CRUD de Libros con MongoDB y TypeScript

## Tecnologías Utilizadas

* **Lenguaje:** TypeScript / Node.js
* **Base de Datos:** MongoDB 
* **Ejecución:** `tsx` 

En este repositorio se va a encontrar la resolucion del TP de DB de UTN. Me parecio un trabajo bastante entretenido, no me encontre con muchos obstaculos durante
el avance del trabajo. La IA fue utilizada unicamente con fines educativos y para agregar algunas cosas nuevas que no fueron vistas en clases ( por ejemplo: en una de las primera partes del codigo, en vez de usar el CLG que siempre se usa se utilizo un TABLE, para que cuando veamos la lista de libros que hay, aparezcan de forma ordenada y estructurada, siendo mas facil de entender)
